# Meesho Reseller Performance Optimization Engine

A business analyst case study that leverages **behavioral + transactional clustering** to identify high-potential reseller segments and design targeted interventions — driving **₹2.10 Cr/month net GMV uplift** for Meesho.

Built from the ground up using **Meesho’s 2023–24 Annual Report** as the strategic foundation, this project reflects Meesho’s core differentiator: **its reseller-driven social commerce model**.

##  Why This Project Stands Out
- **Strategically aligned**: All hypotheses, segments, and interventions are grounded in Meesho’s stated priorities:  
  > *“Deepening reseller engagement”*, *“FCF-positive unit economics”*, and *“Tier 2+ growth”*.
- **Actionable & quantified**: Proposes **behaviorally intelligent nudges** (cashback, badges, WhatsApp messages) with **real GMV impact**.

---

##  Key Results
| Segment | Intervention | Net GMV Impact (₹ Cr/month) |
|--------|-------------|------------------------------|
| Ghost Reseller (14.3%) | ₹20 cashback + WhatsApp nudge | ₹0.84 Cr |
| Social Catalyst (15.1%) | “Top Reseller” badge + trending catalog | ₹0.75 Cr |
| Niche Specialist (17.1%) | Category-specific training | ₹0.51 Cr |
| **Total** | | **₹2.10 Cr/month** |

>  **Net impact after incentive costs** | **Near-zero marginal cost** | **Fully leverages existing Meesho infrastructure**
